# Web Creation BD

Create a professional agency website header inspired by the background color, hover behavior, and subtle effects of bnp.blue9.org.

HEADER BACKGROUND & BEHAVIOR:
- Initial state: transparent header over hero section
- On scroll:
  - Header background smoothly transitions to solid deep dark green (#0f3d2e)
  - Add subtle bottom shadow for separation
- Transition must be smooth (0.3s–0.4s ease-in-out)

LAYOUT STRUCTURE:
- Logo on the left
- Main navigation menu centered or right-aligned
- Auth actions on the right:
  - Login (outline style)
  - Sign Up (solid CTA)

MENU ITEMS (Bangla):
- Facebook Ads
- Web Development
- Graphics Design
- Video Editing
- Motion Graphics
- About Us
- Contact Us

BUTTON STYLES:
- Login button:
  - Transparent background
  - White text
  - Green border
  - On hover: background fills with dark green, text stays white
- Sign Up button:
  - Solid red (#c4161c)
  - White text
  - On hover: slightly darker red

HOVER & MICRO-INTERACTIONS:
- Menu items:
  - Color changes to red on hover
  - Subtle underline or bottom border animation
- Buttons:
  - Slight scale-up (max 1.03)
  - No bounce, no flashy animation

STYLE NOTES:
- Serious, trustworthy, corporate feel
- No gradients, no glassmorphism
- Clean political-style authority adapted for business agency  aita ki tik acce
